# 恢复日文原版

## 方法一：删除补丁

1. 关闭游戏。
2. 在虚拟系统 SD 卡中打开：
   `SD:/atmosphere/contents/01003080177CA000/`
3. 删除本汉化补丁提供的 `romfs` 文件夹，或移除该 Title ID 对应的汉化文件夹。
4. 重启虚拟系统后启动游戏，即恢复原版日文。

不要删除 `SD:/atmosphere/contents/` 下其他 Title ID 的文件夹。

## 方法二：使用原版备份

如果安装前备份过对应目录，将汉化补丁目录移除后，把原版备份恢复到原位置即可。

## 注意

恢复操作不会删除游戏存档。不要删除 Nintendo 或用户存档目录；本补丁只修改 LayeredFS 覆盖文件。
