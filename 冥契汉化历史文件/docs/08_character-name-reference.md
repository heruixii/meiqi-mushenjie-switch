# 人物名核对记录

## 采用规则

本项目的角色名以电脑端汉化常用译名为准，并用 Switch 原文中的全名和独立姓名字段交叉核对。独立姓名字段只替换为对应中文名；普通叙述中的同字词不做全局盲替换，避免把「未来」「环」等普通词误改。

## 公开核对来源

- [维基百科：冥契的牧神节](https://zh.wikipedia.org/zh-hans/冥契的牧神节)：列出主要角色的简体中文名及日文名。
- [ENTERGRAM 官方角色页](http://www.entergram.co.jp/lupercalia/character05.html)：核对 Switch/PS4 版角色的日文姓名和设定。若页面地址发生变化，以 ENTERGRAM 官方站的《冥契のルペルカリア》角色页为准。

公开资料用于核对姓名，不直接替代游戏文本上下文。译文最终仍以游戏内自称、亲属关系和剧情揭示为准。
