# 《冥契的牧神节》翻译规范

## 总原则

剧情翻译以完整理解场景为前提，不按词语逐个替换。先结合前后文、说话人、人物关系和当前演出理解原意，再用自然的简体中文重写。译文应像中文视觉小说原本就这样写成，同时保留原作的情绪、节奏、信息揭示和角色差异。

## 翻译顺序

1. 先阅读同一场景的连续文本，确认叙事视角、时间、地点和人物关系。
2. 再翻译对白、旁白、选项和演出文字，避免脱离上下文单独处理。
3. 结合后续剧情回看伏笔、双关和身份揭示，必要时修订前文。
4. 最后检查中文读感、换行、控制码和文本框长度。

## 人物语言

- 濑和环使用自然、略带男性口语感的第一人称表达；旁白不能机械保留日语句式。
- 仓科双叶保持冷淡、疏离、一本正经又带有宅文化吐槽的语气。
- 架桥琥珀根据剧情阶段区分日常温和语气与舞台/真相段落的压迫感。
- 匂宫巡、箱鸟理世、天使奈奈菜、龙木悠苑、天乐来来、白坂花等角色分别保持自己的礼貌程度、成熟度和说话节奏。
- 演剧台词可以比日常对白更正式、更夸张；不要为了口语化而削弱戏剧效果。
- 称呼以人物关系和场景为准，不能看到名字就统一替换成同一种敬称。

## 名称和术语

角色名以 `glossary/人物名表.csv` 为准。只对确认的姓名字段进行自动映射；对白中的名字、昵称、真名和敬称必须结合语境人工确认，不能全局盲替换。

## 中文表达

- 日语省略的主语根据上下文补足或保留省略，不强行逐句对应。
- 日语惯用表达优先转换为自然中文，不保留生硬的“非常地”“这样地”等结构。
- 语气词、停顿、重复和省略号按中文阅读习惯调整，但不能抹掉人物情绪。
- 双关、反讽、隐喻和舞台台词优先保留功能；无法等值转换时，在备注中记录判断。
- 不擅自增加原文没有的剧情信息，不把不确定的推测写成确定事实。
- 成人内容、残酷描写和强烈情绪按照原作语气翻译，不进行无依据的弱化或夸张。

## 技术要求

- `@n`、`@p`、`@v...` 等控制码必须保留并放在正确位置。
- 不写入 NUL 字符，不改变文本记录之外的二进制结构。
- 每批文本完成后执行控制码检查、回写校验和中文字体覆盖检查。
- 中文过长时优先自然断句，再根据实机画面调整换行；不得为了塞进文本框删掉关键内容。

## 翻译状态

```text
未翻译 -> 初译完成 -> 语境复核 -> 术语检查 -> 实机润色 -> 已实机验证
```

初译完成不等于最终定稿。涉及伏笔、身份、关系变化或演剧台词的文本，必须在相关剧情完成后进行二次复核。
